# ✈️ TripSplit

**国内・海外旅行の費用をスムーズに精算するための、高機能割り勘プランナー**

「誰がいくら払ったっけ？」「外貨だと計算が面倒…」といった旅行中のストレスを解消するために設計された、直感的でパワフルなWebアプリケーションです。

---

## ✨ 主な機能

### ⚙️ 旅行設定

* **柔軟なカスタマイズ**: 旅行タイトルや基準通貨（精算用通貨）をいつでも設定可能。
* **自動保存機能**: ブラウザのローカルストレージを利用し、リロードしてもデータが消えません。
* **クイックリセット**: セッションの全データを一括クリアして新しい旅行を始められます。

### 👥 参加者管理

* **メンバー登録**: 旅行メンバーを自由に追加・編集できます。
* **データの整合性**: すでに支出データが紐付いている参加者の削除を制御し、計算の不整合を防止します。

### 💰 支出管理（マルチ通貨対応）

* **スマート入力**: 現地通貨での支払いをその場で記録。
* **整理されたリスト**: 支出が増えても一覧モーダル機能により、画面をスッキリ保ちます。

### 💱 為替レート

* **リアルタイム取得**: 外部APIから最新のレートを自動取得。
* **手動微調整**: 必要に応じてレートを手動で上書き設定可能です。
* **日本円最適化**: JPY換算時は、視認性を高めるため100円単位での表示に対応しています。

### 🧮 精算計算・出力

* **最適化アルゴリズム**: 送金回数が最小限になるよう計算し、誰から誰にいくら払うかを可視化。
* **サマリー表示**: 全体の総支出と、各個人の差額を分かりやすく表示します。
* **出力機能**: 精算結果を**PNGまたはPDF**としてダウンロードし、メンバーに共有可能です。

## 🔑 API設定

本アプリケーションでは為替レート取得に [exchangerate.host](https://exchangerate.host/) を利用しています。実行にあたっては、**ご自身の API Access Key** が必要です。

1. [exchangerate.host](https://exchangerate.host/) でアカウントを作成し、Access Keyを取得してください。
2. プロジェクト直下に `.env.local` ファイルを作成します。
3. 以下の内容を入力してください：

```env
NEXT_PUBLIC_EXCHANGE_RATE_API_KEY=あなたのAPIキー

```

> [!CAUTION]
> **セキュリティ上の注意**: APIキーを含んだ状態でのGitHubへの公開・共有は絶対に行わないでください。

## 🚀 起動方法

### 1. ローカルでの実行

```bash
# パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

```

ブラウザで `http://localhost:3000` を開いてください。

### 2. Docker を使用する場合

```bash
# コンテナのビルドと起動
docker compose up --build

```

ブラウザで `http://localhost:3000` を開いてください。
